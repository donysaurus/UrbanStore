# UrbanStore Workspace Rules

## Git Workflow (Learned via `/learn`)
- Setelah user selesai prompting dan eksekusi kode selesai (serta lolos verifikasi lint/build bila ada perubahan kode), **selalu buat `git commit`** dengan commit message yang relevan dan deskriptif (Conventional Commits).
- **Jangan pernah menjalankan `git push`** kecuali user secara eksplisit meminta untuk push.
- Pastikan file sensitif seperti `.env` tidak ikut ter-commit.
